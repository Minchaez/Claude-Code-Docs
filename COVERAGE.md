## 상태 정의


| 기호  | 의미                                       |
| --- | ---------------------------------------- |
| ⬜   | 미착수                                      |
| 📖  | 읽음 — 문서를 읽었다                             |
| 🔧  | 확인함 — 실제로 실행하거나 만들어서 내용을 손으로 검증했다        |
| 🧠  | 소화함 — 다른 기능과의 경계를 설명할 수 있고, 남에게 설명할 수 있다 |
| ⛔   | 보류 — 지금 나에게 불필요하다고 판단함 (이유 필수)           |


> ⛔ 도 결론이다. 빈칸으로 두지 말고 명시적으로 표기할 것.
