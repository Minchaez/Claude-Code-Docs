## 절차

### 1. 상태 파악

아래 두 곳을 읽는다.

- `COVERAGE.md` — 각 페이지의 현재 상태(⬜/📖/🔧/🧠/⛔)를 확인
- `log/` 디렉토리의 가장 최근 파일 — 최근 학습 흐름과 헷갈린 부분 확인

### 2. 다음 페이지 선택

아래 우선순위로 딱 한 페이지를 고른다. 나열하지 않는다.

1. README.md의 Layer 순서를 따른다. 이전 레이어에 ⬜나 📖가 남아 있으면 그것부터 (레이어를 건너뛰지 않는다)
2. 📖에서 멈춘 페이지가 있으면 새 페이지보다 그것을 🔧로 올리는 걸 우선한다
3. 노트 파일의 "남은 질문" 섹션에 답이 되는 페이지가 있으면 최우선
4. 인자가 전달된 경우(예: `/next hooks`) 해당 주제로 범위를 좁힌다

### 3. 출력 형식

정확히 아래 형식으로, 짧게 답한다.

```
**다음: <페이지 이름>** (<현재 상태> → <목표 상태>)
- 왜 지금인가: 한 줄
- 문서: <URL>
- 읽기 전 답해볼 질문: 한 줄
- 손으로 확인할 것: 실행할 명령 또는 만들 파일 하나
- 끝나면: COVERAGE.md 상태 갱신 + notes/<경로> 작성
```

### 4. 예외 처리

COVERAGE.md에서 근거를 못 찾으면 추측하지 말고, 무엇을 먼저 채워야 추천이 가능한지 알린다.
