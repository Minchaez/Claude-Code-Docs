# index/by-need.md — 요구사항 → 기능 역색인

노트를 쓰다가 "이런 요구사항이면 이걸 쓰겠구나" 싶을 때 한 줄씩 적립한다.
미리 채우지 않는다. 노트(`notes/`)에서 파생되어야 한다.

## 사용법

페이지 노트를 작성하다가 요구사항→기능 대응이 떠오르면:
1. 아래 표에 한 줄 추가한다
2. "근거 문서"에 공식 URL, "내 노트"에 해당 노트 파일 경로를 적는다
